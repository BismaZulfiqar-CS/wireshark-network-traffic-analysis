**# Wireshark – Network Traffic Analysis & SOC Labs
## Overview**
This repository documents my hands-on learning experience through six practical Wireshark SOC lab activities completed as part of my cybersecurity internship.

I successfully completed all six labs and achieved full marks in every activity.

**## Practical Labs Completed**
1. **Identify the Attacker's IP** – Analysing network packets to identify suspicious IP addresses.
2. **Follow TCP Stream 1** – Investigating TCP communication and examining exchanged data.
3. **Follow TCP Stream, Part 2** – Exploring TCP streams and identifying hidden information.
4. **HTTP Plain Text Credentials** – Understanding the security risks of transmitting credentials over unencrypted HTTP.
5. **Catch the Brute Force Attacker** – Identifying repeated login attempts and suspicious network behaviour.
6. **Catch the Call Scammer** – Investigating call-related network traffic.

**## Skills and Tools**
- Wireshark
- Network traffic analysis
- Packet filtering and inspection
- TCP stream analysis
- HTTP protocol analysis
- Basic security threat investigation

**## Learning Outcomes**
These practical exercises improved my understanding of network protocols, packet analysis, suspicious network behaviour and common cybersecurity threats.
